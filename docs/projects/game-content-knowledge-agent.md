# Game Content Knowledge Agent

## 한 줄 소개

AI가 기존 게임 자료를 활용할 때 참고할 수 있는 정보와 자동화하면 안 되는 영역을 구분한 게임 콘텐츠 제작 절차입니다.

## 해결하려던 문제

게임 콘텐츠 자동화에서는 “만들 수 있는 것”과 “자동으로 만들면 안 되는 것”을 구분해야 합니다. 특히 다음 영역은 자동화 범위를 엄격히 제한해야 합니다.

- 확률, 보상과 경제 수치
- 운영 환경에 직접 반영되는 코드
- 이미지, 사운드, 애니메이션과 실제 리소스
- 원본 운영 소스에 대한 직접 수정

## 작업 흐름

```text
사용자 기획서
  -> 운영 규칙 확인
  -> 정리된 참고 자료 검색
  -> 안전한 참고 자료 선택
  -> 구현 초안 작성
  -> 사용한 근거 기록
  -> 사람이 처리할 작업 정리
```

## 운영 규칙

- 운영 소스는 읽기 전용으로 취급합니다.
- 확률, 보상과 경제 수치는 자동 생성하지 않습니다.
- 실제 게임 리소스는 자동화 대상에서 제외합니다.
- 운영 환경에 반영하는 마지막 단계는 사람이 처리합니다.
- 참고 자료가 충돌하면 임의로 선택하지 않고 충돌 사실을 보고합니다.
- AI가 만든 요약은 참고 자료로만 사용하고 규칙과 원본 근거를 우선합니다.

## 프로젝트의 의미

이 프로젝트는 많이 생성하는 AI보다 통제하고 검토할 수 있는 AI 제작 방식을 보여줍니다. 결과에는 참고한 근거와 사람이 직접 처리해야 할 작업을 함께 남깁니다.
