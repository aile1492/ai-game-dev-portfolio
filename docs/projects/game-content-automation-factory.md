# Game Content Automation Factory

## 한 줄 소개

게임 콘텐츠 제작에서 반복되는 기획서 해석, 데이터 작성, 코드 초안 생성, 등록과 검증을 하나의 작업 흐름으로 묶은 자동화 설계입니다.

## 해결하려던 문제

게임 콘텐츠 제작에서는 다음 작업이 반복됩니다.

- 기획서에서 콘텐츠 이름, 식별자와 주요 규칙 찾기
- 클라이언트 설정 데이터와 JavaScript 초안 만들기
- 서버용 C++ 코드 초안 만들기
- 등록 파일과 설정 파일의 변경 항목 정리
- 누락된 식별자, 파일 이름과 등록 항목 확인
- QA와 출시 전 확인 목록 작성

작은 누락도 QA와 출시 일정에 영향을 줄 수 있으므로, 사람이 매번 수동으로 처리하기보다 검증 가능한 절차로 만드는 것이 목표입니다.

## 작업 흐름

```text
기획서
  -> 구조화된 입력
  -> 생성 계획
  -> 클라이언트 코드와 데이터 초안
  -> 서버 코드 초안
  -> 등록 항목 초안
  -> 검증 보고서
  -> 사람의 최종 검토와 반영
```

## 주요 기능

- 콘텐츠 이름과 식별자를 바탕으로 프로젝트 파일 구조 생성
- 클라이언트 설정 데이터와 JavaScript 초안 생성
- 서버용 C++ 헤더와 소스 초안 생성
- 등록 대상 파일과 확인 목록 생성
- 생성 결과 검증 보고서 작성

## AI 활용 원칙

AI가 운영 코드에 직접 반영하지 않습니다. 기획서 요약, 반복 코드 초안, 누락 가능성 확인과 문서화를 돕고, 최종 결과는 사람이 검토합니다.

## 공개 범위

- 실제 회사 소스 코드 제외
- 확률, 보상, 경제 수치 제외
- 내부 파일명, 운영 데이터와 배포 정보 제외
- 공개 자료는 설계 의도와 정제된 작업 흐름 중심으로 구성

## 사용 기술

Python, Tkinter, JavaScript, C++
