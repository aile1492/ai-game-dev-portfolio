## Career Summary

2018년부터 상용 게임 서비스의 클라이언트 개발과 운영에 참여하며 다수의 게임 콘텐츠 제작 경험을 쌓았습니다. Cocos Creator와 JavaScript를 기반으로 인게임 로직, 보너스 흐름, UI 인터랙션, 인게임 연출을 구현했으며, 최근에는 C++ 기반 서버 로직과 클라이언트-서버 흐름까지 업무 범위를 확장하고 있습니다.

개인 프로젝트에서는 AI를 활용한 개발 자동화와 생산성 도구 제작에 집중했습니다. Game Content Automation Factory에서는 게임 콘텐츠 제작 과정의 반복 작업을 자동화하는 구조를 설계했고, Game Content Knowledge Agent에서는 knowledge pack 기반의 안전한 AI 제작 workflow를 정리했습니다. UE5 Pipeline Health Agent에서는 Unreal Engine 5 프로젝트의 로그, 설정, 에셋 상태를 분석해 pipeline health report를 생성하는 도구를 제작했습니다.

## Project Bullets

- 게임 콘텐츠 제작 과정에서 반복되는 데이터 작성, 코드 초안 생성, 등록, 검증 흐름을 자동화하기 위한 Game Content Automation Factory 설계
- 기존 상용 게임 콘텐츠 구조를 knowledge pack으로 정리하고 safe reference selection, forbidden automation boundary, manual integration policy를 둔 Game Content Knowledge Agent 정리
- Unreal Engine 5 프로젝트의 `.uproject`, `Config`, `Saved/Logs`, `Content` 상태를 분석하는 UE5 Pipeline Health Agent 제작
- Epic 공식 Stack O Bot 샘플의 실제 editor log를 스캔해 AutomationTool 실패 신호를 탐지하고 false positive를 줄이도록 rule 보정
- Tree-sitter, ChromaDB, LangGraph를 활용한 Code Search Agent 제작
- 검색, 페이지 읽기, 분석, 리포트 작성을 단계화한 AI Research Agent 제작

## Caution

- UE5와 Python은 주력 실무 역량이 아니라 AI Tooling 포트폴리오에서 활용한 확장 경험으로 표현합니다.
- Game Content Automation Factory는 실행형 생성 자동화 도구이고, Game Content Knowledge Agent는 knowledge pack 기반 AI 제작 workflow로 구분해 설명합니다.
- 두 게임 자동화 프로젝트 모두 실무 병목에서 출발했지만, 공개 자료에는 회사 내부 자산, 운영 데이터, 민감한 게임 수치, 실제 파일명을 포함하지 않습니다.
- AI 활용 경험은 "AI가 대신 만들었다"가 아니라 "AI를 제한된 workflow와 검증 구조 안에 넣었다"로 설명합니다.
