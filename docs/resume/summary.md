# 이력서용 요약

## 직무 제목

게임 클라이언트 개발자 · AI 협업 게임 제작 · 개발 자동화

## 한 줄 소개

상용 게임 클라이언트 개발 경험을 바탕으로 AI와 함께 게임을 만들고, 게임 제작에서 발견한 반복 업무를 개발 도구로 확장하는 개발자입니다.

## 핵심 경험

- 상용 게임 클라이언트 개발 및 운영 경험 8년
- 슬롯형 게임 콘텐츠 50종 이상 제작
- Cocos Creator, JavaScript, C++, TypeScript 기반 실무 개발
- Word Bloom 기획, 구현, Android 빌드와 Google Play 출시
- Sweet Crunch와 2048 Puzzle을 통한 AI 협업 게임 제작
- Game QA Agent, Code Search Agent와 AI Research Agent 등 개발 보조 도구 구현

## 대표 프로젝트

### Word Bloom

단어 퍼즐 규칙, 화면 흐름, 저장, 모바일 조작을 구현하고 일부 그래픽 제작에 ComfyUI를 활용했습니다. 기획부터 Google Play 출시까지 혼자 진행했습니다.

### Sweet Crunch

TypeScript와 Phaser 3로 같은 그림 맞추기 퍼즐의 보드 처리, 연쇄 제거, 특수 블록과 레벨 데이터 구성을 구현했습니다.

### Game QA Agent

Sweet Crunch의 레벨 데이터와 실제 Browser 행동을 반복 검사하고, 같은 오류를 다시 실행할 수 있는 Trace와 한국어 보고서를 만드는 QA 자동화 도구를 구현했습니다.

### Code Search Agent

코드 구조와 의미를 함께 분석해 질문과 관련된 파일과 함수를 찾고, 코드 근거와 함께 답변하는 검색 도구를 구현했습니다.

### AI Research Agent

질문을 조사 항목으로 나누고 검색, 읽기, 분석, 보고서 작성을 단계별로 수행하며 출처를 남기는 조사 보조 도구를 구현했습니다.

## 사용 기술

- 실무 주력: C++, JavaScript, TypeScript, Cocos Creator
- 게임 제작: Godot, GDScript, Phaser 3, ComfyUI
- AI 개발 도구: Python, FastAPI, LangGraph, Next.js
- AI 협업: Claude, Gemini, Codex

## 경험 범위 표기

- Unreal Engine 5는 공식 샘플을 분석해 점검 도구를 만든 보조 프로젝트 경험입니다.
- Python은 AI 개발 도구와 자동화 프로젝트를 통해 활용 범위를 넓힌 언어입니다.
- 회사 내부 소스, 운영 데이터, 민감한 게임 수치와 실제 내부 파일명은 공개하지 않습니다.
