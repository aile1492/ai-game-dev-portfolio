# Chrono Studio Job Fit

## Target Role

Chrono Studio 개발 자동화 엔지니어 포지션은 게임 개발 전반에 활용되는 AI 도구를 설계하고, 반복 업무 자동화와 개발 워크플로우 최적화를 담당하는 역할입니다.

공고상 핵심 키워드는 다음과 같습니다.

- 게임 개발 전반에 활용되는 AI 도구 설계 및 개발
- 반복 작업 자동화 및 생산성 향상 시스템 구축
- AI Agent를 활용한 개발 워크플로우 최적화
- AI Pair Programming 환경 구축
- 내부 개발 생산성을 극대화하기 위한 AI Tooling 제작
- Python 또는 TypeScript 사용 경험
- Unreal Engine 이해
- Agent, MCP, Tool-use 구조 관심

## Matching Projects

### Game Content Automation Factory

게임 콘텐츠 제작 과정의 반복 작업을 자동화하는 AI Tooling 프로젝트입니다.

연결되는 공고 항목:

- 반복 작업 자동화
- 내부 개발 생산성 향상
- 게임 개발 프로세스 이해
- AI 기반 workflow 구축

### Game Content Knowledge Agent

기존 상용 게임 콘텐츠 구조를 knowledge pack으로 정리하고, AI가 안전한 참조를 선택해 구현 초안을 만들도록 제한한 AI-assisted creation workflow입니다.

연결되는 공고 항목:

- AI Agent 기반 개발 workflow
- Tool-use와 Retrieval 기반 지식 참조 구조
- 내부 개발 생산성을 위한 AI Tooling
- AI 생성 결과의 검증과 manual review boundary 설계

### UE5 Pipeline Health Agent

UE5 프로젝트의 로그, 설정, 에셋 상태를 자동 분석하는 pipeline health check 도구입니다.

연결되는 공고 항목:

- Unreal Engine 개발 환경 이해
- Python 기반 개발 자동화
- 개발 파이프라인 점검
- CI preflight check
- AI summary guardrail

### Code Search Agent

코드베이스 탐색을 자동화하는 AI 개발 생산성 도구입니다.

연결되는 공고 항목:

- AI Agent 활용 개발 workflow
- 내부 개발자 생산성 도구
- Retrieval 기반 code context search
- Tool-use 구조

### AI Research Agent

검색, 읽기, 분석, 리포트 작성을 단계별로 수행하는 Agent workflow 프로젝트입니다.

연결되는 공고 항목:

- Agent state 설계
- multi-step tool-use workflow
- source based report generation
- AI workflow 최적화

## Strengths

- 게임 콘텐츠 제작 실무 경험이 있어 도구 사용자의 업무 흐름을 이해합니다.
- 반복 작업을 코드 생성뿐 아니라 등록, 검증, 리포트까지 연결된 파이프라인으로 바라봅니다.
- AI 결과물을 그대로 신뢰하지 않고 deterministic rule, validation, manual review boundary를 함께 설계합니다.
- Cocos Creator, JavaScript, C++ 서버 로직 경험을 바탕으로 클라이언트와 서버 흐름을 함께 고려할 수 있습니다.
- Python과 TypeScript를 AI Tooling 및 개인 프로젝트에서 활용했습니다.

## Risk And Honest Positioning

### Unreal Engine

Unreal Engine은 실무 주력 경험이 아닙니다. 대신 UE5 공식 샘플 프로젝트를 분석 대상으로 삼아 로그와 설정, 에셋 상태를 자동 점검하는 개발 도구를 제작했습니다.

표현 방식:

```text
UE5 실무 콘텐츠 개발 경험보다는, UE5 프로젝트를 분석하고 개발 자동화 도구로 연결한 개인 포트폴리오 경험이 있습니다.
```

### Python

Python은 실무 주력 언어라기보다 AI Tooling과 자동화 프로젝트에서 활용 범위를 확장한 언어입니다.

표현 방식:

```text
주력 실무 언어는 JavaScript와 C++이며, Python은 AI Agent, 로그 분석, 자동화 도구 제작을 통해 실무형 도구 개발에 활용하고 있습니다.
```

### AI Tools

AI Coding Tool 사용 경험은 프로젝트 진행과 도구화 경험을 중심으로 설명하는 것이 적절합니다.

표현 방식:

```text
AI를 단순 코드 생성 도구로 사용하기보다, 프로젝트별 지침, 검증 기준, 문서화 흐름을 함께 설계해 개발 생산성 도구로 활용했습니다.
```

## Interview Message

저는 게임 클라이언트 개발 경험을 바탕으로, 반복적인 제작 업무를 AI와 자동화 도구로 줄이는 방향에 관심을 확장해왔습니다. Game Content Automation Factory에서는 게임 콘텐츠 제작 과정의 데이터 작성과 코드 초안 생성, 등록, 검증 흐름을 자동화하는 구조를 설계했고, Game Content Knowledge Agent에서는 knowledge pack, safe reference selection, manual integration boundary를 둔 AI 제작 workflow를 정리했습니다. UE5 Pipeline Health Agent에서는 Unreal Engine 5 프로젝트의 로그와 설정, 에셋 상태를 분석해 개발 파이프라인의 위험 신호를 리포트화했습니다. AI가 임의로 판단하지 않도록 rule 기반 finding과 검증 가능한 리포트를 먼저 만들고, AI는 그 결과를 요약하고 action item으로 정리하는 방식에 집중했습니다.
